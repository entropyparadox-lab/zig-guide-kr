## 주요 구성 (Three-Track Architecture)

<CardGrid stagger>
	<Card title="🚀 타 언어 개발자를 위한 Zig" icon="rocket">
		C/C++, Rust, Go, Python/TypeScript 개발자를 위해 기존 언어의 멘탈 모델과 Zig의 시스템 프로그래밍 패러다임을 1:1로 비교 대조합니다.
	</Card>
	<Card title="📖 Zig 실전 핸드북 (Track B)" icon="document">
		입문자부터 실무 시스템 엔지니어까지 단계별로 따라하며 완성하는 직관적인 핸드북입니다. 환경 설정부터 `build.zig`, Allocator 패턴, Comptime, C FFI까지 실무 중심으로 다룹니다.
	</Card>
	<Card title="📚 공식 레퍼런스 완역 (Track A)" icon="open-book">
		Zig 0.16.0 공식 Language Reference를 1:1로 원문 그대로 충실하게 한글화했습니다. 스펙과 문법을 깊이 있게 참조할 때 활용하세요.
	</Card>
	<Card title="⚙️ CI 기반 코드 자동 검증" icon="setting">
		문서에 포함된 모든 Zig 예제 코드는 GitHub Actions CI를 통해 실제 `zig test` 및 `zig build-exe`로 유효성을 자동 검증합니다.
	</Card>
</CardGrid>
