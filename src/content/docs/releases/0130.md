# Zig 0.13.0 릴리스 노트 요약

:::note[과거 릴리스 아카이브]
이 문서는 Zig 0.13.0 릴리스 노트 아카이브입니다. 현재 최신 안정 버전은 **[Zig 0.16.0](/zig-guide-kr/releases/0160/)**입니다.
:::

---

## 1. 주요 변경점 요약

1. **`build.zig.zon` 패키지 매니저 도입**:
   - URL 기반 tarball 의존성 선언 및 지문(Fingerprint) 해시 무결성 검증 체계 안착.
2. **`std.http.Client` 기본 내장**:
   - 외부 libcurl 없이 순수 Zig으로 구현된 TLS/HTTP 1.1 클라이언트 제공.
3. **C 코드 생성 백엔드 안정화**:
   - LLVM 없는 경량 C 코드 방출 백엔드 개선.
