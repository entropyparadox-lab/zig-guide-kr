# Zig 0.14.0 릴리스 노트 요약

:::note[과거 릴리스 아카이브]
이 문서는 Zig 0.14.0 릴리스 노트 아카이브입니다. 현재 최신 안정 버전은 **[Zig 0.16.0](/zig-guide-kr/releases/0160/)**입니다.
:::

---

## 1. 주요 변경점 요약

1. **빌드 시스템 모듈화 기반 마련**:
   - `root_module` 중심의 빌드 그래프 설계 도입 시작.
2. **`std.Thread` 및 동기화 프리미티브 개선**:
   - `std.Thread.spawn` API 단순화 및 POSIX/Windows 스레드 계층 통합.
3. **에러 추적(Error Return Traces) 고도화**:
   - 디버그 모드에서 스택 트레이스와 결합된 상세 에러 리턴 경로 출력 지원.
