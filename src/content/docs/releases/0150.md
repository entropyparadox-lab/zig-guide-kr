# Zig 0.15.0 릴리스 노트 요약

:::note[과거 릴리스 아카이브]
이 문서는 Zig 0.15.0 릴리스 노트 아카이브입니다. 현재 최신 안정 버전은 **[Zig 0.16.0](/zig-guide-kr/releases/0160/)**입니다.
:::

---

## 1. 주요 변경점 요약

1. **컴파일러 성능 및 메모리 점유 최적화**:
   - 대규모 코드베이스에서의 AST 메모리 점유율을 20% 감소.
2. **`build.zig` 패키지 매니저 안정화**:
   - `build.zig.zon` 의존성 해시 검증 및 오프라인 캐시 안정성 향상.
3. **타깃 아키텍처 지원 확장**:
   - RISC-V 64비트 및 LoongArch64 타깃의 코드 생성 최적화.
