# Zig 0.17.0 릴리스 노트 & 변경점 요약

Zig 0.17.0은 **1.0 릴리스를 향한 언어 안정화(Language Stability)**, **C 번역 레이어의 모듈화 분리**, **Struct-Of-Arrays 스타일 리플렉션**, 그리고 **빌드 시스템 러너(Maker/Configurer) 분리 및 성능 최적화**를 골자로 공식 배포되었습니다.

---

## 1. 주요 하이라이트 (Highlights)

1. **언어 안정화 진전 (Language Stability Progress)**:
   - 25개 이상의 언어 제안이 정식 채택되고 125개 이상의 비표준 제안이 정리되었습니다.
   - `void{}` 구문 삭제 (`{}` 통일), `errdefer |err|` 캡처 삭제, `**` 배열 곱셈 삭제(`@splat` 대체) 등 언어 코어가 더욱 단순하고 직관적으로 수렴했습니다.
2. **`@cImport` 제거 및 C 번역 분리**:
   - 컴파일러 내장 `@cImport`가 완전히 삭제되었으며, `b.addTranslateC` 또는 독립 `translate-c` 패키지를 통한 모듈 주입(`@import("c")`) 방식으로 완전히 전환되었습니다.
3. **컴파일타임 리플렉션 Struct-Of-Arrays (SoA) 전환**:
   - `@typeInfo(T).@"struct"`와 `@"union"`, `@"enum"`이 기존 단일 배열 순회에서 `field_names`, `field_types`, `field_attrs` 구조로 분리되어 대규모 메타프로그래밍 성능이 향상되었습니다.
4. **빌드 시스템 고도화 (Build System Overhaul)**:
   - Maker 프로세스와 Configurer 프로세스가 분리되어 `build.zig` 수정 시 매번 빌드 러너를 재빌드하지 않아도 됩니다.
   - `b.args` 대신 `run_cmd.addPassthruArgs()`가 도입되었습니다.
5. **메모리 할당자 및 표준 라이브러리 개선**:
   - `std.fmt.allocPrint`가 `mem.Allocator.print`로 통합되었습니다.
   - `allocator.dupeZ` 대신 `allocator.dupeSentinel(u8, slice, 0)`로 통일되었습니다.
   - `BufferFirstAllocator`가 기존 `StackFallbackAllocator`를 대체합니다.
   - 디버그 메모리 할당자로 스레드 안전성과 카나리 보호가 강화된 `SafeAllocator`가 도입되었습니다.

## 2. 언어(Core Language) 핵심 변경점

### `@cImport` 제거
C 헤더 인클루드는 더 이상 언어 차원의 빌트인이 아닌 빌드 시스템 레벨에서 처리됩니다.

```zig
// pseudo
// build.zig
const translate_c = b.addTranslateC(.{
    .root_source_file = b.path("src/c_imports.h"),
    .target = target,
    .optimize = optimize,
});
exe_mod.addImport("c", translate_c.createModule());
```

```zig
// src/main.zig
const c = @import("c");
```

### `void{}` 문법 삭제
`void{}`는 유효하지 않은 문법이며 빈 구조체 리터럴 `{}`를 사용해야 합니다.

```zig
return {};
```

### 배열 곱셈 문법 `**` 삭제
`[1]u8{0} ** N` 문법 대신 `@splat`을 사용합니다.

```zig
const buffer: [64]u8 = @splat(0);
```

### `@backingInt` 및 `@fromBackingInt`
기존 `@intFromEnum`과 `@enumFromInt`를 대체하는 새로운 정수 변환 빌트인이 추가되었습니다.

```zig
const Color = enum(u8) { red = 1, green = 2 };
const raw: u8 = @backingInt(Color.red);
const col: Color = @fromBackingInt(raw);
```

### `@divCeil` 빌트인 추가
양의 무한대 방향으로 올림하는 정수 나눗셈 빌트인이 추가되었습니다.

```zig
const val = @divCeil(5, 3); // 2
```

## 3. 표준 라이브러리(std) 주요 변경점

### `mem.Allocator`
- `allocator.print("...", .{...})`로 포맷 스트링 할당 간소화
- `allocator.dupeSentinel(T, slice, sentinel)`로 센티널 종단 슬라이스 복사

### `std.ArrayList`
- `list.getLastOrNull()` → `list.last()`로 명칭 변경
- `list.getLast()` → `list.last().?` 사용 권장
- `list.lastPtr()` 추가 (?*T 포인터 반환)

### `std.lang.Optimize`
- `std.builtin.OptimizeMode`가 `std.lang.Optimize`로 개편
- 태그명 소문자화: `.debug`, `.safe`, `.fast`, `.small`
