# Zig 0.17.1

[공식 다운로드 인덱스](https://ziglang.org/download/index.json)는 **0.17.1**을 2026-11-02 릴리스로 제공합니다. 언어 문서는 [0.17.1 공식 레퍼런스](https://ziglang.org/documentation/0.17.1/), 표준 라이브러리는 [0.17.1 std](https://ziglang.org/documentation/0.17.1/std/)를 기준으로 확인하세요.

공식 인덱스의 릴리스 노트 링크는 여전히 [0.17.0 릴리스 노트](https://ziglang.org/download/0.17.0/release-notes.html)를 가리킵니다. 별도로 확인되지 않은 버그 수정 목록이나 새로운 언어 변경을 0.17.1의 변경점으로 단정하지 않습니다. 0.17.0의 API 전환과 0.17.1 패치 기준을 구분합니다.

## 이 가이드에서 바뀐 점

- CI와 도구 검증 컴파일러를 안정판 0.17.1로 고정합니다. `tracked_versions.json`의 `latest_release`도 0.17.1입니다.
- 0.17 계열 레퍼런스 경로 `docs/0.17.0`은 유지합니다. 0.16.0 아카이브는 보존하며 현재 컴파일러 검증 대상에서 제외합니다.
- 테스트 실패를 `build-obj` 성공으로 바꾸던 fallback을 제거했습니다. 테스트 블록은 실제 테스트를 실행하고 main 예제는 본문을 컴파일합니다.
- 빌드 예제는 `zig build --help`로 그래프를 평가합니다. 누락된 외부 소스까지 전체 빌드하는 검증은 아닙니다. 선언 전용 예제의 모든 함수 본문 분석도 보장하지 않습니다.
- 엄격한 검증에서 드러난 현재 트랙의 I/O, 메모리 정렬, 스레드, JSON, 리플렉션 및 빌드 API 예제를 수정했습니다.
- 브라우저 플레이그라운드는 실제 Zig 실행기가 아닌 **JavaScript 예제 시뮬레이터**로 표시합니다. 준비된 출력은 컴파일·실행·성능·누수 검증의 증거가 아닙니다.
- PR에서 네이티브 검증과 Astro 빌드를 실행합니다. 기존 main 자동 Pages 배포는 그대로입니다.

## 재현 명령

Zig 0.17.1을 PATH에 지정한 뒤 `pnpm test`와 `pnpm build`를 실행하세요. 테스트 블록은 `zig test -lc`, main 예제는 `zig build-exe -lc`를 사용하며 C 예제 검증을 위해 libc를 링크합니다. 의사 코드와 추가 모듈이 필요한 `// ignore` 블록은 명시적으로 제외합니다.
